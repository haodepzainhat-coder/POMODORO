Hướng Dẫn Sử Dụng StudyFlow

Tối ưu hiệu quả học tập và quản lý thời gian của bạn

1. Phương Pháp Pomodoro Cốt Lõi

Học tập theo các phiên đếm lùi (mặc định 25 phút tập trung cao độ + 5 phút nghỉ ngắn). Sau 4 ca tập trung liên tục, ứng dụng sẽ tự động chuyển sang chế độ Nghỉ dài (15 phút) giúp phục hồi năng lượng não bộ.

2. Kế Hoạch Tuần, Thứ & Mục Tiêu Con

Lập danh sách việc cần làm cho từng tuần và từng thứ cụ thể. Bạn có thể thêm các mục tiêu con checklist lồng ghép bên trong. Click vào ô checkbox hoặc chữ để hoàn thành; giữ biểu tượng ⋮⋮ để kéo thả thay đổi thứ tự ưu tiên.

3. Cửa Sổ Nổi PiP (Picture-in-Picture)

Bấm nút PiP trên thanh menu để ghim chiếc đồng hồ nổi tí hon ở góc màn hình, giúp bạn vừa đọc tài liệu, xem video bài giảng vừa quan sát được số phút đang đếm lùi.

4. Lưu Trữ Trực Tiếp Lên Google Sheet

Kết nối với Google Sheet của riêng bạn để lưu trữ vĩnh viễn mọi dữ liệu học tập và thống kê mà không lo bị mất kể cả khi đổi máy.

Kết Nối Google Sheet Lưu Trữ Dữ Liệu

Lưu trữ kế hoạch và thời gian học tập của bạn an toàn

  1. Mở một Google Sheet mới trên máy tính của bạn.
  2. Vào menu Tiện ích mở rộng (Extensions) ➔ chọn Apps Script.
  3. Xóa sạch toàn bộ code cũ và dán đoạn mã bên dưới vào:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var doc = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = doc.getSheetByName('StudyFlow') || doc.insertSheet('StudyFlow');
    sheet.clear();
    sheet.getRange(1, 1).setValue(JSON.stringify(data));
    return ContentService.createTextOutput(JSON.stringify({status: 'success'}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({status: 'error', message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  try {
    var doc = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = doc.getSheetByName('StudyFlow');
    var raw = sheet ? sheet.getRange(1, 1).getValue() : "{}";
    return ContentService.createTextOutput(raw)
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
